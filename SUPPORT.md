# GrapeCompare Support

GrapeCompare processes selected files locally and does not upload comparison contents.

## Get help

1. Update with `brew upgrade --cask grapecompare` or install the latest [GitHub release](https://github.com/everettjf/GrapeCompare/releases/latest).
2. Search [existing issues](https://github.com/everettjf/GrapeCompare/issues).
3. If the problem remains, open a bug report with the GrapeCompare version, macOS version, Mac model, reproduction steps, and approximate file sizes or folder counts.

Use only non-sensitive sample data and redact private paths from screenshots and logs.

Feature ideas are welcome through the feature request form. Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
