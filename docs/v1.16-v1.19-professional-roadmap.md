# GrapeCompare v1.16–v1.19 Professional Roadmap

This roadmap closes the remaining professional-workflow gaps while preserving
GrapeCompare's macOS 14 baseline, deterministic comparison core, bounded resource
usage, and transactional filesystem guarantees.

## v1.16 — Git Repository Workspace

- Persistent repository library with security-scoped bookmarks.
- Worktree discovery and switching without checkout.
- Current branch, upstream, ahead/behind, and merge-base shortcuts.
- Paginated commit graph with parent and reference decorations.
- Flat and tree changesets with stable file identity.
- Previous/next changed-file navigation and persistent reviewed state.
- Live working-copy badges without reading or uploading file contents.

Acceptance: Git fixtures cover detached HEAD, no upstream, multiple worktrees,
merge commits, renames, partially staged files, and unsafe paths. A 10,000-file
changeset must build its tree in bounded linear memory.

## v1.17 — Image Pro

- Synchronized zoom and pan; Two-Up, One-Up, Split, Blink, and Difference modes.
- Navigator, pixel inspector, channel selection, and configurable threshold.
- Explicit manual alignment plus optional local Vision alignment.
- SVG rasterization through system frameworks with strict pixel limits.

Acceptance: pixel counts remain exact at threshold zero; dimensions, alpha, color
channels, offsets, malformed images, SVGs, and maximum-pixel limits have fixtures.
Interactive state never retains duplicate full-resolution decoded rasters.

## v1.18 — Folder Sync Pro

- Reusable ignore profiles with previewable matching rules.
- Mirror, Update, and Custom operation plans.
- Permission and extended-attribute comparison.
- Exportable operation report and CLI `--dry-run` plan output.
- APFS clone-copy fast path with safe fallback and transactional undo.

Acceptance: every mutation is preflighted, root-contained, symlink-safe, reportable,
and recoverable. Dry-run and execution resolve to the same normalized plan. Large
directory scans retain bounded parallelism and memory.

## v1.19 — Apple Developer Formats

- Semantic `.xcstrings` comparison.
- Stable, section-aware `.pbxproj` comparison.
- `.app`, `.framework`, `.bundle`, and package browsing.
- Code signature, entitlements, provisioning, and Mach-O metadata comparison.
- Asset catalog structure and rendered-image comparison.

Acceptance: malformed and adversarial fixtures never execute bundled content or
follow symlinks. External tools have the same timeout, cancellation, and output
limits as Git. Every semantic viewer has deterministic fallback to ordinary diff.

## Release gates

Every milestone runs core and CLI tests, a Debug app build, localization validation,
benchmark regression checks, and direct-release validation. v1.19 additionally
requires a clean universal signed/notarization candidate audit and documentation
that distinguishes App Store sandbox capabilities from direct distribution.

## Distribution capability boundary

| Capability | App Store sandbox | Direct distribution / Homebrew |
| --- | --- | --- |
| User-selected files, folders, bundles, and asset catalogs | Yes, through security-scoped selection | Yes |
| Persistent repository library | Security-scoped bookmarks | Bookmarks with direct-path fallback |
| Git difftool/mergetool temporary paths | Only when explicitly granted | Yes |
| Finder shortcut | macOS 15+ | macOS 15+ |
| Local comparison, image alignment, signature and Mach-O inspection | Yes | Yes |
| Uploading compared content | Never | Never |

The direct build is intentionally unsandboxed so Git can provide arbitrary temporary
paths. Neither build launches inspected bundles, follows directory symlinks, or sends
file contents to a service.
