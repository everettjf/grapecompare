# GrapeCompare 1.0.3 (39)

## Changes

- Stage inputs individually. Two compatible inputs start comparison automatically.
  Keep up to 16 file versions on the input shelf and explicitly select Left and Right.
  Three files remain on the shelf; three-way merge requires an explicit action and role confirmation.
  The shelf lasts for the current workspace. Removing an item releases its shelf access grant.
- Search folder comparisons by filename or relative path, ignoring case and accents.
  Matching ancestors expand automatically; search intersects the existing status filters.
- Collapse unchanged text with three lines of surrounding context, expand any group,
  and automatically reveal search/line-navigation targets. Both text layouts use original row IDs;
  output editing and patch generation retain the complete comparison.
- Restore local reading state per ordered input pair: text search, folding, wrapping and
  scroll positions; folder search, status filter, expansion, selection and top visible row.
  The bounded local history survives restarts and stores no compared file contents.
