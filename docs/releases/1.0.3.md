# GrapeCompare 1.0.3 (40) — release candidate, not uploaded

## Build 40 changes

- Keep the folder sidebar visible when opening a text or image comparison.
  Previous/Next File follows the search/status-filtered changed-file sequence.
  Advancing beyond the first/last text difference moves to the adjacent file;
  directory navigation stops at the sequence boundaries.
- Add versions and choose Left/Right from the comparison-page input shelf, with
  image thumbnails. Switching inputs protects unsaved output with save/discard/cancel;
  a failed save keeps the edits and current comparison.
- Restore image zoom, pan, mode, split, threshold, channel selection and alignment
  by ordered input pair. Ignore stale asynchronous difference calculations.
- Paste PNG/TIFF clipboard images as private PNG snapshots. On Home, the first
  image is staged and the second starts comparison. Pasting in an existing
  comparison adds a version without replacing the current inputs.

App Store metadata, product documentation, UI baseline reference checks, correctness
and sandbox audit, Debug compilation, signed universal Release archive, and archive

# GrapeCompare 1.0.3 (39)

## Changes

- Stage inputs individually. Two compatible inputs start comparison automatically.
  Keep up to 16 file versions on the input shelf and explicitly select Left and Right.
  Three files remain on the shelf; three-way merge requires an explicit action and role confirmation.
  The shelf lasts for the current workspace. Removing an item releases its shelf access grant.
- Search folder comparisons by filename or relative path, ignoring case and accents.
  Matching ancestors expand automatically; search intersects the existing status filters.
- Collapse unchanged text with three lines of surrounding context, expand any group,
  and automatically reveal search/line-navigation targets. Both text layouts use original row IDs;
  output editing and patch generation retain the complete comparison.
- Restore local reading state per ordered input pair: text search, folding, wrapping and
  scroll positions; folder search, status filter, expansion, selection and top visible row.
  The bounded local history survives restarts and stores no compared file contents.

## Verification (2026-10-01)

- Debug build and universal signed Release archive passed with App Sandbox enabled.
- Localization extraction/catalog, icons, product documentation, App Store metadata,
  correctness audit, archive entitlements, universal architectures and App Intent checks passed.
- Native UI tests passed: stage one file; add a second and compare automatically;
  reject mixed input without losing the shelf; add a third without forcing a merge;
