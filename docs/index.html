Installation and supported workflows

Requires macOS 15 or later, on Apple silicon or Intel. Install from the Mac App Store, the supported distribution channel. GitHub provides source code; Homebrew and historical GitHub release downloads are not supported installers for the current app.

To start a comparison, choose two files or folders in the app. You can also use Finder Open With, drag and drop, or the Compare Files Shortcut. The app can access only items you select.

Three-way text and image merging uses manually selected base, left, and right inputs. Git integration, difftool/mergetool hooks, and a standalone CLI are not included.
