GrapeCompare for macOS

Support

GrapeCompare performs comparisons locally in App Sandbox. No account or network connection is required.

Before reporting a problem

Update to the latest Mac App Store version, reopen the files or folders through the app's Choose buttons, and repeat the operation. GrapeCompare can access only items you explicitly select.

Report a bug

Open a GitHub issue with the GrapeCompare version, macOS version, Mac model, reproduction steps, and approximate file sizes or folder item counts. Do not attach confidential comparison content.
